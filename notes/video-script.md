# Solution Video Script (≤5 min)

Per the brief's required structure — script it before recording so you
don't run over on time.

| Time | Section | What to show/say |
|---|---|---|
| 0:00–0:45 | Problem + baseline | Who has this problem, the bottleneck, the simple baseline approach |
| 0:45–3:00 | Full execution | One realistic run start to finish, real screen capture, not narration-over-slides |
| 3:00–4:00 | Final comparison | The results table — baseline vs. agent, the number that matters |
| 4:00–4:40 | Changelog highlight | The single change that contributed most, in one sentence + evidence |
| 4:40–5:00 | Removed experiment | One thing you tried and cut, and what it taught you |
